# City Hotels Booking API — лабораторная работа №2

## Назначение

REST API сервиса бронирования отелей. API является контрактом между Web/Manager Portal и Backend Service из лабораторной работы №1. Через него клиент регистрирует пользователя, выполняет вход, ищет отели и номера, создаёт бронирования, управляет номерами отеля и оставляет отзывы.

## Роли и правила доступа

- **Guest** — регистрация и вход, просмотр отелей и номеров, управление собственными бронированиями, публикация отзывов после проживания.
- **Manager** — все операции гостя для чтения, а также создание и изменение отелей и номеров, просмотр бронирований и отзывов своих отелей.

Аутентификация выполняется по JWT Bearer token. Если токен отсутствует или недействителен, API возвращает `401 Unauthorized`. Если пользователь вошёл, но роль не позволяет операцию, возвращается `403 Forbidden`.

## REST API Specs

| Метод | URI | Назначение | Доступ | Успешный код |
|---|---|---|---|---|
| POST | `/api/v1/auth/register` | Регистрация гостя или менеджера | Все | 201 Created |
| POST | `/api/v1/auth/login` | Вход и получение JWT | Все | 200 OK |
| GET | `/api/v1/hotels` | Поиск и фильтрация отелей | Публичный | 200 OK |
| GET | `/api/v1/hotels/{hotelId}` | Получить карточку отеля | Публичный | 200 OK |
| POST | `/api/v1/hotels` | Зарегистрировать отель | Manager | 201 Created |
| PATCH | `/api/v1/hotels/{hotelId}` | Изменить сведения об отеле | Manager-владелец | 200 OK |
| GET | `/api/v1/hotels/{hotelId}/rooms` | Получить номера и доступность | Публичный | 200 OK |
| POST | `/api/v1/hotels/{hotelId}/rooms` | Добавить номер | Manager-владелец | 201 Created |
| PATCH | `/api/v1/rooms/{roomId}` | Изменить цену, категорию или статус | Manager-владелец | 200 OK |
| GET | `/api/v1/bookings` | Список бронирований текущего пользователя | Guest/Manager | 200 OK |
| POST | `/api/v1/bookings` | Создать бронирование | Guest | 201 Created |
| GET | `/api/v1/bookings/{bookingId}` | Получить одну бронь | Владелец/Manager | 200 OK |
| POST | `/api/v1/bookings/{bookingId}/cancel` | Отменить бронь | Владелец/Manager | 200 OK |
| GET | `/api/v1/hotels/{hotelId}/reviews` | Получить отзывы отеля | Публичный | 200 OK |
| POST | `/api/v1/hotels/{hotelId}/reviews` | Оставить отзыв | Guest | 201 Created |

### Принятые HTTP-статусы

- `200 OK` — успешное чтение или изменение;
- `201 Created` — создан новый ресурс;
- `400 Bad Request` — ошибка формата или бизнес-валидации;
- `401 Unauthorized` — отсутствует или недействителен JWT;
- `403 Forbidden` — недостаточно прав;
- `404 Not Found` — ресурс не найден;
- `409 Conflict` — номер уже занят на выбранные даты;
- `422 Unprocessable Entity` — корректный JSON не проходит проверку полей;
- `500 Internal Server Error` — непредвиденная ошибка сервера.

## Связь с моделью данных

API использует сущности из первой лабораторной: `User`, `Hotel`, `Room`, `Booking`, `Review`. Идентификаторы передаются как UUID. Итоговая стоимость бронирования фиксируется при создании и не пересчитывается при последующем изменении цены номера.
