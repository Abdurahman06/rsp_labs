# Архитектура: Сервис аренды автомобилей (Carsharing / Rental API)

## Краткое описание проекта
Система представляет собой бэкенд для сервиса каршеринга. Она позволяет пользователям находить, бронировать и арендовать автомобили, а операторам автопарка — управлять состоянием машин и отслеживать поездки. Основные особенности: учет пробега и уровня топлива, контроль статуса доступности авто и предварительная блокировка депозита перед поездкой.

## Ролевая модель и Use Cases

### 1. Водитель (Driver)
**Use Cases (Сценарии использования):**
- Регистрация и авторизация в приложении.
- Поиск свободных автомобилей на карте (с фильтрацией по уровню топлива/модели).
- Бронирование автомобиля.
- Старт поездки (с холдированием/блокировкой депозита на карте).
- Завершение поездки (списание средств за аренду, разблокировка остатка депозита).
- Просмотр истории своих поездок.

### 2. Оператор автопарка (Fleet Operator)
**Use Cases (Сценарии использования):**
- Добавление новых автомобилей в систему.
- Изменение статуса автомобиля (например, "В ремонте", "Доступен").
- Мониторинг телеметрии автомобилей в реальном времени (пробег, уровень топлива, локация).
- Просмотр статистики и истории аренд всех водителей.
- Управление тарифами на аренду.

### Описание таблиц, ключей и ограничений

1. **Таблица `USERS` (Пользователи)**
   - `id` (UUID, Primary Key) — уникальный идентификатор.
   - `role` (VARCHAR, NOT NULL) — роль (Водитель, Оператор).
   - `phone` (VARCHAR, UNIQUE, NOT NULL) — телефон.
   - `license_number` (VARCHAR, UNIQUE) — номер водительского удостоверения.
   - **Индексы**: по полям `phone` и `license_number` для быстрого поиска при авторизации.

2. **Таблица `VEHICLES` (Автомобили)**
   - `id` (UUID, Primary Key) — уникальный идентификатор авто.
   - `license_plate` (VARCHAR, UNIQUE, NOT NULL) — гос. номер.
   - `status` (VARCHAR, NOT NULL) — статус (AVAILABLE, IN_USE, MAINTENANCE).
   - `fuel_level` (INT, CHECK(fuel_level >= 0 AND fuel_level <= 100)) — уровень топлива.
   - `mileage` (INT, CHECK(mileage >= 0)) — пробег.
   - **Индексы**: по полю `status` для быстрого поиска свободных машин.

3. **Таблица `TARIFFS` (Тарифы)**
   - `id` (UUID, Primary Key).
   - `name` (VARCHAR, UNIQUE, NOT NULL) — название тарифа.
   - `price_per_minute` (DECIMAL, NOT NULL) — цена за минуту.

4. **Таблица `RENTALS` (Аренды / Поездки)**
   - `id` (UUID, Primary Key).
   - `user_id` (UUID, Foreign Key -> USERS.id, NOT NULL).
   - `vehicle_id` (UUID, Foreign Key -> VEHICLES.id, NOT NULL).
   - `tariff_id` (UUID, Foreign Key -> TARIFFS.id, NOT NULL).
   - `status` (VARCHAR, NOT NULL) — статус аренды.
   - **Индексы**: по внешним ключам `user_id`, `vehicle_id` для быстрого получения истории поездок.

5. **Таблица `PAYMENTS` (Транзакции и Депозиты)**
   - `id` (UUID, Primary Key).
   - `user_id` (UUID, Foreign Key -> USERS.id, NOT NULL).
   - `rental_id` (UUID, Foreign Key -> RENTALS.id, NULLable) — привязка к поездке (может быть NULL, если это просто пополнение баланса).
   - `type` (VARCHAR, NOT NULL) — тип (DEPOSIT, PAYMENT, REFUND).
   - `status` (VARCHAR, NOT NULL) — статус (PENDING, SUCCESS).
   - **Индексы**: по `rental_id` для поиска платежей, связанных с конкретной поездкой.
