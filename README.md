# Лабораторная работа №3 — Clean/Layered Architecture

Каркас `City Hotels Booking API` на Python. Работа продолжает проектирование предметной области из ЛР1 и REST-контракт из ЛР2.

## Что реализовано

- слои `controller`, `service`, `repository`;
- загрузка настроек из `.env`;
- безопасный шаблон `.env.example`;
- рабочие `GET /health` и `GET /api/v1/health`;
- JSON-ответ с названием, версией, статусом и временем работы;
- `.gitignore` для секретов, зависимостей, кэшей и IDE-файлов;
- спецификация `openapi.yaml` из ЛР2.

## Запуск

```bash
python -m cmd.app.main
```

По умолчанию сервер слушает `127.0.0.1:8080`. Настройки можно переопределить в локальном `.env` на основе `.env.example`.

Проверка:

```bash
curl http://127.0.0.1:8080/health
```
