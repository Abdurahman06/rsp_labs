# Лабораторная работа №2 — REST API сервиса бронирования отелей

Проектирование REST API для `City Hotels Booking API` по стандарту OpenAPI 3.0. Спецификация описывает аутентификацию, поиск отелей и номеров, создание и отмену бронирований, а также отзывы.

## Состав работы

- `ARCHITECTURE.md` — архитектурный отчёт и сводная таблица REST-эндпоинтов;
- `openapi.yaml` — машинно-читаемый контракт API OpenAPI 3.0.

## Проверка спецификации

Файл можно открыть в Swagger Editor или Swagger UI. Все защищённые операции используют Bearer JWT в заголовке `Authorization`.

Тема и сущности согласованы с лабораторной работой №1: пользователи, отели, номера, бронирования и отзывы.
